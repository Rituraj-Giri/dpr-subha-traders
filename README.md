# D.P.R. Subha Traders — React + Vite

A premium, responsive website concept for D.P.R. Subha Traders, listed as a paint store on Satdobato–Tikabhairab Road, Lalitpur, Nepal.

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Before publishing

- Confirm the business name, address, phone number and opening hours with the owner.
- Confirm actual paint brands, product categories, stock, prices and services. The current page intentionally avoids inventing inventory.
- Replace illustrative room photos with approved photographs of the real store/products where possible.
- Colour swatches are inspiration only, not actual product shades or paint codes.
- Add the owner's social accounts only after receiving the correct links.
- Connect a domain and deploy the built site to Vercel or another static host.

## Stack

- React 18
- Vite 6
- Lucide React icons
- Plain CSS (responsive layouts, mobile menu, interactive palette selector)
